# Darkum Design | Marketing Copy Reference

**Created:** 2026-08-14
**Restructured:** 2026-08-15 — reorganized into **Live (Current)** / **Proposed (In-progress)** per platform, each with a checkbox, per Sobhy's direction.

**Standing rules for everything in this file:**
- **No em dashes, anywhere, in either language.** Use a comma, colon, semicolon, or period instead.
- **Word choice: "Shop" (EN) / "محل" (AR)** — not "Studio" / "استوديو".
- Arabic slogan is **translated, not transliterated**: أثاث · فن · تصميم.

**How to use this doc:**
- **Live (Current)** is only filled in once verified: pasted directly by Sobhy from the platform itself, or read directly from a source file Claude has access to (e.g. `index.html`).
- **Proposed (In-progress)** is drafted once the Live baseline is known, using LinkedIn's copy as the source-of-truth brand voice/content, tailored to each platform's character limit and format.
- Check the **Live** box once Live and Proposed match and the update is actually live on the platform.
