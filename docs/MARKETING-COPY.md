# Darkum Design | Marketing Copy Reference

**Created:** 2026-08-14
**Purpose:** Single source of truth for all reusable marketing/bio copy across platforms. Previously lived inline in `HANDOFF.md` §8 — moved out to its own file so a single word or slogan change doesn't require re-editing a long project handoff doc. `HANDOFF.md` now just links here.

**Standing rules for everything in this file:**
- **No em dashes, anywhere, in either language.** Use a comma, colon, semicolon, or period instead. (Previously an Arabic-only rule; extended to English 2026-08-14 after the ChatGPT-drafted reference copy came back full of them.)
- **Word choice: "Shop" (EN) / "محل" (AR)** — not "Studio" / "استوديو". Decided 2026-08-14. Reasoning: Noura's own source material never used "studio"; "Shop" matches the physical store + upcoming WooCommerce store more literally, and lines up with the `FurnitureStore` JSON-LD schema type already on the coming-soon page. "محل" chosen over "متجر" per Sobhy's direction (more natural/colloquial register than the more formal "متجر").
- Arabic slogan is **translated, not transliterated**: أثاث · فن · تصميم (not the transliteration فرنيتشر · آرت · ديزاين). Applied consistently across YouTube and LinkedIn.

**Propagation status (as of 2026-08-14):** the Shop/محل wording below is the *correct, current* version. It has **not yet been re-published** to YouTube (currently live with the old shorter draft, see note in that section) or LinkedIn (drafted, pending Sobhy's publish). Update this file first when wording changes, then treat it as the checklist for what still needs pushing live on each platform.
