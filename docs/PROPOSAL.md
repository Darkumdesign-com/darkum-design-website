## 3. Line Item Details

### 1. Logo & Brand Mark — 5,000 EGP *(revised down from 12,000, validated against 2 real quotes)*
Full brand mark design, delivered in a complete multi-format export system: 6 file formats (PNG, JPG, WebP, SVG, EPS, AI), 3 color variants (Black/White/Transparent), 4 layout variants (Circular, Exact, Favicon, Horizontal), across raster sizes from 410×489 up to print-resolution 300ppi and full vector — 176 files total, all correctly named and verified.

### 2. Social Media Presence — 3,000 EGP *(revised down from 12,000, quote-check in progress — see §5)*
One-time creation and setup of the business's social footprint — this is presence *creation*, not ongoing monthly *management* (which would be a separate future retainer):
- Accounts established across 9 platforms: Facebook, Instagram, Threads, TikTok, YouTube, Pinterest, X, Messenger, and Google Business Profile (pending verification)
- Bio/About copywriting for each platform, in English and colloquial Egyptian Arabic where applicable (LinkedIn tagline + full About description, GBP description, Open Graph description)
- Business email infrastructure set up on the custom domain (`info@`, `finances@`, `marketing@`, `webmaster@darkumdesign.com` via Zoho)
- Unified-inbox tooling recommended and configured guidance (Metricool)
- Business phone number integration guidance across platforms

### 3. Coming-Soon Page — 9,000 EGP ⚠️ not yet spot-checked
Live bilingual (English/Arabic, side-by-side) placeholder page: custom animated catchphrase carousel, brand-accurate styling, mobile-responsive layout fixes, Open Graph/Twitter Card meta tags, JSON-LD structured data for search engines, all social links wired and verified live.

### 4. Website — Full WordPress/WooCommerce Build — 35,000 EGP ⚠️ not yet spot-checked
One-page homepage/landing site built on WordPress + WooCommerce, using Kadence Blocks + Kadence theme (chosen specifically to avoid ongoing software subscription costs), Yoast SEO, and the full sliding hero catchphrase carousel (bilingual, direction-aware animation) once Bido provides the complete phrase list. Includes one highly customizable product (Bed Frame) at the WooCommerce/catalog level — the configurator logic itself is priced separately below.

### 5. Bed Frame Product Configurator — 18,000 EGP ⚠️ not yet spot-checked
This is effectively a small custom application, not a standard WooCommerce product setup: multi-select Position field, conditional Insertion counts (0–4) per Position, Material selection, image-swatch leg picker, free-text engraving field, customer image upload, and Size logic that's conditional on both Position *and* Insertion count — the most complex nested logic in the whole build.

**This price is fixed regardless of which plugin ends up being used** (Advanced Product Fields or the ThemeComplete alternative) — the actual work is planning and building the conditional-logic blueprint itself, which is the same either way; the plugin is just the tool it gets built in. **Plugin licensing cost itself is not included in this proposal** and is not something Sobhy can front — Darkum Design/Bido will need to purchase the chosen plugin directly from the vendor.
